# Отчёт о вредоносном ПО: червь Bukkit «kto.Core» / «.shame»

**Дата подготовки:** 05.09.2026
**Для:** newvirus@kaspersky.com (Лаборатория Касперского)
**Язык:** русский / English summary at the end

---

## 1. Сводка

В Minecraft-сборках для серверов Purpur/Paper/Spigot (версия игры 1.16.5) обнаружен
самозапускающийся Java-червь, распространяющийся через файлы плагинов (`.jar`).

- Имя Java-класса-точки входа: **`kto.Core`**
- Маркеры внутри заражённых `.jar`: **`kto/Core.class`**, файл **`.shame`**,
  переименованный оригинал конфигурации **`plugin.yml.orig`**
- Открытый ключевой файл конфигурации плагина: `plugin.yml` (в нём подменяется
  поле `main:` на `kto.Core`)
- Суффикс/маркер заражения: файл `.shame`

## 2. Поведение червя

1. **Распространение.** Заражённый JAR ведёт себя как плагин Bukkit с `main: kto.Core`.
   При загрузке сервером заражённого jar выполняется статический блок `<clinit>`
   класса `kto.Core` → `Core.start`. Код рекурсивно обходит файловую систему
   (`findAllPluginsDirs`, `searchPluginsRecursive`) и находит все каталоги `plugins/`
   на всех дисках.
2. **Инфицирование.** Для каждого найденного `.jar` плагина:
   - оригинальный `plugin.yml` переименовывается в `plugin.yml.orig`;
   - внутрь добавляются `kto/Core.class` и файл-маркер `.shame`;
   - `plugin.yml` перезаписывается с `main: kto.Core`.
   Это приводит к самозапуску червя при следующем старте любого сервера в этой папке.
3. **Кража/распространение через временную папку.** В `%TEMP%` создаются
   промежуточные копии вида `tmp_<случайное_число>.jar` (в нашем случае
   `C:\Users\liker\AppData\Local\Temp\tmp_*.jar`), содержащие те же маркеры.
4. **Нагрузка на CPU.** Во время заражения процесс сервера длительно
   (минуты) занимает ~100% одного ядра CPU, рекурсивно сканируя каталоги;
   сервер «зависает» на этапе загрузки плагинов и долго не доходит до «Done».

## 5. Среды распространения (подозрение)

Все заражённые jar находились в сборках, файлы которых были взяты с сайта
распространения «leaked»/крякнутых плагинов:

- **https://mcdev.ru** — источник плагинов (в т.ч. премиум),
  используемых в сборках; подозрение, что червь распространяется именно
  через скачанные с этого сайта файлы, прошитые в сборки.

Просим лабораторию проверить/связаться с площадкой (или провести анализ
происхождения) по данному вектору распространения.

## 6. Затронутые платформы

- Модифицированный ядро: **Purpur** (Paper-fork) версии 1.16.5,
  git-Purpur-1171 (API 1.16.5-R0.1-SNAPSHOT).
- Java: JRE 17 (Oracle) и Temurin 21 — на устойчивой фазе червь работает
  в любых JVM, независимо от версии (классам хватает Java 8+).
- ОС: Windows 10/11 (тест на Windows 11 64-bit).

## 7. Методика детекции и очистки

Детекция зип-архивов `.jar` по именам элементов внутри:

```
kto/core.class, .shame, plugin.yml.orig
```

Очистка (итеративная, в том же цикле):
1. Если в jar есть `plugin.yml.orig` — восстановить его как `plugin.yml`.
2. Удалить все файлы с префиксом `kto/` и `.shame`.
3. Сохранить прочие файлы без изменений.
4. Перезаписать jar через временный файл (атомарный `os.replace`).

## English Summary

**Malware type:** Java worm/trojan infecting Bukkit/Paper/Purpur plugin jars.
**Entry class:** `kto.Core` (plugin `main:` = `kto.Core`).
**Markers inside infected jars:** `kto/Core.class`, `.shame`, `plugin.yml.orig`.
**Behavior:** on plugin load, statically scans all drives for any `plugins/` dirs,
rewrites every plugin jar (renames `plugin.yml`→`plugin.yml.orig`, injects itself,
sets `main: kto.Core`), causing re-execution on next server start; also drops
`%TEMP%\tmp_*.jar` copies. Slave CPU ~100% during spread — server freeze.
**Dropper SHA-256:** `5EBAEE3BADB162D3A5A9402A27D535C7093572CB170A879CA5FF556543810E04`
**C2 (based on PCAP/flow):** `papa.ultimatebox.fun:20011` → `185.176.94.50`.
**Distribution vector suspicion:** premium plugins downloaded from **https://mcdev.ru**.
**Scale observed:** 593 infected jars across all server builds on Windows machine,
05-09-2026. Cleaned; 3858 jars verified clean after cleanup.

Please analyze `kto/Core.class`, attribute a malware name, and correlate C2.
